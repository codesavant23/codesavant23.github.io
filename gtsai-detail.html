Overview

GenTestsAI is a framework designed to automatically generate unit tests for Python projects using Large Language Models (LLMs). Developed as part of a Bachelor's thesis, it explores an alternative approach to traditional test generation techniques such as Search-Based Software Testing (SBST).

The framework takes an entire Python project as input and produces structured test suites for each module, enabling developers to accelerate testing workflows with minimal manual effort. While primarily built around open-source LLMs, its modular architecture allows integration with external providers (e.g., OpenAI) through customizable inference accessors.

GenTestsAI is aimed at researchers, individual developers, and small teams, with the long-term vision of supporting more complex and large-scale software systems.

Challenge

Designing GenTestsAI required addressing several non-trivial challenges inherent to LLM-based code generation.

One of the primary difficulties was crafting effective prompt templates capable of producing meaningful and coherent unit tests across a wide variety of code structures. Early iterations revealed that raw generation alone was insufficient: generated tests were often syntactically incorrect or semantically unreliable.

This led to the introduction of iterative correction mechanisms, where generation, syntax fixing, and linting validation are repeated multiple times. However, this introduced a key trade-off: improved reliability comes at the cost of increased execution time.

Additional challenges included:

  • Handling non-determinism and inconsistency in LLM outputs (such as semantic drifting)
  • Managing limited computational resources (e.g., shared GPU environments)
  • Ensuring scalability across large Python codebases

To mitigate performance issues, a caching system was introduced, enabling resumable executions and reducing redundant computations.

Solution

GenTestsAI is structured as a two-layered system composed of:

  • GenTestsAILib → a reusable, modular library
  • GenTestsAI → the orchestration framework implementing the full workflow

The library is designed following SOLID principles, which grant loosely coupled components and stable interfaces, ensuring extensibility and long-term maintainability. The framework builds on top of it, organizing the theorized workflow into clearly defined functional processes.

Workflow

The core pipeline operates as follows:

  1. Iterate over selected LLMs
  2. Process each module of the input Python project
  3. Extract and analyze source code using AST/CST parsing (default is via Tree-sitter)
  4. Decompose modules into functions and class methods
  5. For each unit:
    1. Generate a partial test suite using the LLM
    2. Apply syntax correction (iterative)
    3. Apply linting correction using the project’s execution environment
  6. If all steps succeed, merge the partial suite into the module’s final test suite
  7. Otherwise, log the failed unit for traceability

Each phase supports configurable retry mechanisms, allowing users to balance execution time and output quality.

Key Components

  • ptsuite_generation

    • Handles generation, validation, and refinement of test suites. It represents the core engine of the framework.

  • focalproj_configuration

    • Manages isolated execution environments ("focal environments") used to validate generated tests against the target project.

Implementation

GenTestsAI provides a highly configurable and extensible system for automated test generation.
Key features include:

  • Automatic unit test generation via LLMs
  • Iterative correction (syntax + linting)
  • Retry mechanisms for robustness
  • Statement-level and function-level coverage analysis
  • Extensive configurability of core components (LLMs, parsers, inference backends, hyperparameters)

The framework currently exposes a CLI interface, but its architecture naturally supports programmatic usage as a Python API.

A major strength of the project lies in GenTestsAILib, which is designed to be fully reusable and adaptable for different test generation workflows and research scenarios.

Limitation & Future work

Despite its capabilities, GenTestsAI still faces several limitations.

Execution time and resource requirements remain significant, especially when working with large codebases or multiple LLMs. Additionally, the inherent non-determinism of LLMs can lead to issues such as hallucinations or semantic drifting, particularly when handling complex logic.

Future improvements include:

  • Introducing semantic drift detection mechanisms
  • Decoupling pre-installed tooling from focal environment construction
  • Expanding support for customizable benchmarking pipelines
  • Improving efficiency through smarter orchestration strategies

These enhancements aim to make the framework more robust, scalable, and suitable for real-world adoption.
